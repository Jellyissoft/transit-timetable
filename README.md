# 환승 시간표 (Transit Timetable PWA)

관리자가 등록한 **시간표 템플릿**으로 **경로**의 환승 시각을 계산하는 오프라인 설치형 웹앱(PWA).
서버 없이 브라우저(localStorage)에 데이터를 저장하며, 아이폰 사파리에서 "홈 화면에 추가"로 앱처럼 설치해 오프라인으로 쓸 수 있다.

## 구성
- `index.html` — UI 셸 + 서비스워커 등록
- `app.js` — 전체 로직(데이터 모델, 입력 파서 5종, 검증, 운행일 판정, 환승 계산 엔진, 4개 탭 UI, 백업/복원)
- `styles.css` — 모바일 우선 스타일
- `manifest.webmanifest` — PWA 매니페스트
- `sw.js` — 오프라인 캐시 서비스워커
- `icons/` — 홈화면 아이콘
- `gen_icons.py` — 아이콘 생성 스크립트(빌드용, 배포 불필요)

## 기능
- **시간표**: 템플릿 CRUD·복제·미리보기. 단순 배차 / 개별 운행편(KTX·ITX·열차). 입력 5종(줄단위·쉼표·CSV·간격 규칙 생성·JSON). 저장 전 검증(시간형식·중복·도착<출발·필수누락·요일미지정).
- **경로**: 구간이 시간표 템플릿 ID를 참조(원본 수정 시 자동 반영). 시간표 검색으로 구간 추가.
- **환승검색**: 경로·날짜·출발 시간창 → 해당일 실제 운행편만 연결 계산. 자정 넘김(`arrivalDayOffset`) 처리.
- **데이터**: JSON 내보내기/가져오기·병합/교체 복원, 공휴일 관리.

## 로컬 실행
```
python -m http.server 8777 --directory .
```
→ http://localhost:8777

## 배포 (GitHub Pages)
정적 파일이라 그대로 올리면 된다. 상대경로로 작성돼 하위 폴더 배포도 동작.
서비스워커(오프라인)는 **HTTPS에서만** 동작하므로 GitHub Pages(HTTPS)가 적합하다.

> 코드를 고쳐 재배포할 때는 `sw.js`의 `CACHE` 값(`transit-tt-v1`)의 버전을 올려야 캐시가 갱신된다.
